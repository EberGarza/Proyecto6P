# ============================================================================
#  Hoja de sprites: Castor (macho)
#
#  Formato
#    imagen <archivo>            imagen, relativa a esta carpeta
#    nombre <texto>              nombre de la hoja (informativo)
#    fondo <r> <g> <b>           color que se vuelve transparente al cargar
#    tolerancia <n>              cuanto puede alejarse un pixel de ese color
#                                y aun considerarse fondo
#    escala <f>                  aumento propio de la hoja
#
#    animacion <Estado> <segundos_por_cuadro> [bucle]
#    tinte <r> <g> <b> [Estado]  color por el que se multiplica el sprite
#    cuadro <x> <y> <w> <h> [ox] [oy]
#
#  A diferencia de la hoja antigua (assets/images/beta/), esta esta dibujada
#  sobre una REJILLA EXACTA de 64x64: 4 columnas por 9 filas. Eso cambia como
#  se ancla el sprite. Antes el anclaje iba sobre la cara, medido pose a pose,
#  porque los recortes no estaban alineados. Aqui el anclaje es el mismo para
#  todos los cuadros (32, 28) y va sobre la CELDA, no sobre el dibujo.
#
#  Esto es a proposito: la sombra del suelo se queda quieta en todos los
#  cuadros y el cuerpo sube y baja respecto a ella. Ese salto lo dibujo el
#  artista dentro de la celda, y anclando por celda se conserva. Si se anclara
#  sobre el cuerpo, el motor "corregiria" el salto y la animacion se quedaria
#  plana.
#
#  Se puede editar y volver a lanzar el juego: no hace falta recompilar.
# ============================================================================

imagen     castor_macho.png
nombre     Castor
fondo      200 224 208

# PNG sin perdida y fondo de un verde plano: basta una tolerancia minima.
tolerancia 12

# La hoja se deja a 1: la pantalla aplica el aumento, y lo hace con un factor
# entero (x3 en la partida, x2 en la vista previa). Ampliar pixel art por un
# factor fraccionario hace que unos pixeles ocupen 3 y otros 4, y eso hormiguea.
escala     1.0
